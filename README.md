# ELI5 Skill

A three-level plain-English explainer skill for Hermes-style agents. It starts with ELI5, Freshman, and an adaptive adult-beginner explanation, then supports sticky follow-ups and simple one-page visual HTML.

This public copy is genericized so it does not depend on a private firm, profile, or internal skill name.

## Contents

- `SKILL.md` - the skill definition
- `references/` - ladder, style, examples, and visual-template guidance
- `assets/` - the icon and a worked visual example
- `agents/openai.yaml` - optional agent metadata
